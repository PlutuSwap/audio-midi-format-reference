# MP3 vs WAV for an Audio-to-MIDI Attempt

This note helps you choose between the two inputs accepted by FIELDNOTE. It compares only the tool's stated workflow; it is not a general audio-engineering benchmark.

| Question | MP3 | WAV |
|---|---|---|
| Does FIELDNOTE accept it? | Yes | Yes |
| Maximum file size | 25 MB | 25 MB |
| Maximum duration | 60 seconds | 60 seconds |
| One file at a time? | Yes | Yes |
| Result | Standard MIDI (`.mid`) | Standard MIDI (`.mid`) |
| Where does the page say processing happens? | In this browser on your device | In this browser on your device |

## Practical choice

Use whichever supported file you already have, provided it meets the size and duration limits. The tool does not publish a comparative accuracy result for MP3 versus WAV, so this guide does not claim one sounds or transcribes better.

## Processing caveat

The live tool describes its output as an experimental note sketch and asks users to review every note. A MIDI file is an editable result, not a promise that every note, rhythm, or instrument will be correct.

For the current tool and its limits, see [FIELDNOTE's MP3 to MIDI page](https://midifromsound.com/). The page's local-processing statement is also described in its [privacy notice](https://midifromsound.com/privacy.html).
